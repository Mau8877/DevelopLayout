# Política de seguridad

## Reportar una vulnerabilidad

No abras un issue público. Usa **Security → Report a vulnerability** en el
repositorio de GitHub (reporte privado). Incluye pasos para reproducir, el
componente afectado (backend, frontend, mobile o infraestructura) y el impacto
que observas.

## Alcance

Este repositorio es una plantilla base: las credenciales de ejemplo
(`.env.example`) y los datos de desarrollo no son secretos reales. Las prácticas
de seguridad que se exigen están en `.claude/rules/SEGURIDAD_OWASP.md`.

## Versiones soportadas

Solo la rama `main`.
